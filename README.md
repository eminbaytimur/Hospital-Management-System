# Hastane Yönetim Sistemi 🏥

Bu proje, temel hastane süreçlerini dijitalleştirmek, hızlandırmak ve daha düzenli bir hale getirmek amacıyla geliştirilmiş bir Hastane Yönetim Sistemi'dir. Hasta kayıtları, doktor randevuları ve idari işlemlerin tek bir platform üzerinden kolayca yönetilmesini hedefler.

## Temel Özellikler
* **Hasta Yönetimi:** Yeni hasta kaydı oluşturma, bilgi güncelleme ve tıbbi geçmiş takibi.
* **Randevu Sistemi:** Doktorların uygunluk durumuna göre randevu alma ve iptal etme.
* **Personel Yönetimi:** Doktor ve diğer hastane çalışanlarının kayıtlarının tutulması.

## Kullanılan Teknolojiler
* WPF (Windows Presentation Foundation)
* C#
* Microsoft SQL Server

# Hospital Management System 🏥

This project is a Hospital Management System developed to digitize, accelerate, and organize fundamental hospital processes. It aims to easily manage patient records, doctor appointments, and administrative tasks through a single platform.

## Key Features
* **Patient Management:** Registering new patients, updating information, and tracking medical history.
* **Appointment System:** Scheduling and canceling appointments based on doctor availability.
* **Staff Management:** Maintaining records of doctors and other hospital staff.

## Technologies Used
* WPF (Windows Presentation Foundation)
* C#
* Microsoft SQL Server
